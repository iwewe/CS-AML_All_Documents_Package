# CS-AML Framework v0.1

**Civil Society Anti-Money Laundering & Financial Intelligence Framework**  
**Status:** Normative Draft  
**Version:** 0.1  
**Date:** October 2026

This Markdown file is a portability companion to the normative DOCX. The DOCX contains the fully formatted standard.

## Core analytical chain

`SOURCE → EVIDENCE → FACT → INDICATOR → HYPOTHESIS → ASSESSMENT → INTELLIGENCE PRODUCT`

## Core domain model

`CASE → SOURCE → EVIDENCE → ENTITY → RELATIONSHIP → ASSET → EVENT → VALUE FLOW → INDICATOR → TYPOLOGY → HYPOTHESIS → ASSESSMENT → INTELLIGENCE PRODUCT`

## Design axioms

1. Evidence is not an allegation.
2. Case is context; Entity and Evidence are reusable truth objects.
3. Every material relationship has provenance.
4. Unknown is a valid value and is preferable to invented precision.
5. Graph structure generates leads, not guilt.
6. Typology similarity is an indicator, not proof.
7. Analytical confidence must reflect both evidence quality and intelligence gaps.
8. Civil society follows value lawfully; it does not imitate coercive state powers.
9. Sensitive data requires proportional protection.
10. A strong intelligence product makes uncertainty visible.
