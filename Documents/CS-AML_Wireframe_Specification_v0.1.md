# CS-AML Wireframe Specification v0.1

**Status:** Normative wireframe baseline for MVP 0.1

## Wireframe axiom
Wireframes SHALL preserve uncertainty, provenance, reversibility and permission boundaries in their spatial hierarchy.

## Global frame
Header → Primary navigation → Context header → Local navigation → Main canvas → Context/evidence rail → Action zone
